# KNOWLEDGE INDEX

- Format authority: [Agent Skills](https://agentskills.io/specification) for skill directories and `SKILL.md` metadata.
- Repository governance: Universal Project Repository (UPR/1) Standard Tier, with native `skills/` directory layout.
- Catalog schema: `catalog.schema.json`. Registry's extra metadata is implementation-specific and **not** part of the Agent Skills specification.
- Consumer compatibility is documented in each skill's `skill.meta.json` and may be unknown until tested.
