# INTENT

**INT-001 — Proposed:** A single canonical public registry lets any tool-equipped AI agent discover skill capabilities before deciding whether it can run or install them. Public discoverability, cross-platform neutrality and low-context catalog reading are goals.

**INT-002 — Proposed:** Separate skill authoring, publication approval and consumer installation. One approved version of skill source; generated metadata, not duplicated instruction files.

**Non-goals:** Implement every agent installer at inception; publish private ChatGPT Library archives indiscriminately; duplicate the owner's internal awareness/context system; turn a skill repository into an execution service.

**Acceptance:** Valid published skills are readable under `skills/<slug>/SKILL.md`, catalog is accurate, CI checks pass, every release is reviewed for secrets, rights and safety; users can open a catalog without installing code.
