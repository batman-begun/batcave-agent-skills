# WonderAnime · Three briefs, one style

WonderAnime applies a gouache and grungecel rendering vocabulary to new images, edits or prompts. Its [public style canon](../../../skills/wonderanime-gouache-grungecel-image/references/style-canon.md) defines color, ink, cel shadows and texture. Try these briefs to see how the choices hold up across subjects.

| Brief | What to inspect |
| --- | --- |
| Mechanic wiping an old scooter at the end of a night shift, with warm tube light and a wet street | Crisp shadows, readable silhouette and scuffs specific to the scooter's materials. |
| A weather station on a snow ridge at blue hour, with a cropped antenna in the foreground | Texture remains visible across snow and metal. The palette and contrast still read as blue hour. |
| An early-morning portrait of a baker shaping dough in a bright kitchen | Restrained ink, matte skin, readable hands and flour texture. |

Run all three with the same provider settings and repeat the rendering core from the canon. Review each result for style consistency and whether it preserves the subject, lighting and framing in its brief.
