# Night Kiln design canon

**User job.** Decide whether the evening workshop fits and complete the demo reservation on a phone.

**UX contract.** Preserve the workshop title, schedule, location, experience level, email label, native email validation and confirmation. Reserve seat is the primary action. The form is local to the fixture.

**Direction.** Use a quiet editorial treatment that borrows its color and typography from ceramics studio signage. Keep density low. Reserve scale changes for the title and booking area. Use no decorative motion.

**Semantic tokens.** Paper separates the page and form surfaces. Ink carries the main text. Terracotta identifies the primary action. A visible outline identifies keyboard focus.

**Validation.** Compare both variants at 390 CSS pixels. Check the same keyboard/form flow and keep the full set of workshop facts visible.
