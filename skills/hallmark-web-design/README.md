# Hallmark Web Design v0.2.1

This is a portable skill adapter for Nutlope/Hallmark pinned at upstream commit `04977e15f3dfd6ee4b74c887dac3eb52665d6c92`.

**Includes:** complete 50/50 *theme catalog*, source-resolution instructions using GitHub or a verified local checkout, preservation-first workflows, MIT attribution, and a script to install the *complete* upstream source into OpenCode/Codex. This plugin can read original theme definitions on demand through GitHub (text) but it is **not a full offline upstream source archive**.

**Not included in the plugin ZIP:** 50 full theme markdown definitions, 50 binary samples, original Node scripts or references. A bootstrap run on a networked Mac recovers all **187 original payload files (7,079,805 bytes)** and checks parity.

Run on Mac after inspecting the script:

```bash
bash scripts/bootstrap-full-hallmark.sh
```

The original source repo is MIT licensed; license notice is included. Do not call a ChatGPT design review a SlopLint/browser pass unless the real original scripts executed.

The MIT notice covers the upstream material. The owner authorized public viewing of this adapter snapshot. No separate reuse license for the adapter has been specified.
