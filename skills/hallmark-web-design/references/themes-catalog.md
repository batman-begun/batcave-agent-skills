## How to fetch actual designs

- Full definition: `skills/hallmark/references/themes/<slug>.md` from GitHub connector, with `ref` pinned above.
- Original visual: same path with `.jpg`. GitHub text connector may reject binary; use a viewable upstream web page or a full local clone for previews.
- Actual selector: `skills/hallmark/scripts/theme.mjs`; matching index: `skills/hallmark/references/themes/index.json`. Use real selector only in a local Node 18+ runtime.
