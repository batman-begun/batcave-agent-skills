# WonderAnime Gouache/Grungecel Image

Gouache here describes the dry surface texture in the WonderAnime V3 Grungecel style. Earlier sunlit gouache and polished oil-like WonderAnime revisions are historical variants. Preserve the current brief's subject, identity, era, wardrobe, action, framing, mood, lighting intent, and requested text.

## Workflow

1. Identify the requested output: a new image, an edit, a prompt, or a review. Generic image requests require a clear WonderAnime cue before applying this style.
2. Read [style canon](references/style-canon.md). Use authorized V3 references as style evidence where available. Label each input as a source to preserve, an identity reference, or a style-only anchor. Preserve the scene and identity from the brief and source. Without visual anchors, work from the text canon and describe fidelity as text-guided.
3. For a new image, write one prompt starting with subject, action and framing. Add the relevant style core and scene-specific defaults. For edits, explicitly list what to keep and which rendering traits to change. For batches, reuse the same style core and record deliberate variations.
4. Use the image capability and references supported by the current host. For prompt-only work or when generation is unavailable, return the compiled prompt. See [provider notes](references/provider-notes.md) when adapting the prompt to a specific interface.
5. Inspect the result using [visual QA](references/visual-qa.md). Correct the largest observed drift while preserving successful parts. Record reference availability and any fidelity or brief issues that remain.

## Edit prompt structure

> Preserve the source's identity, pose, layout, and requested content. Use the style reference for contours, cel shadow shapes, palette and dry texture. Keep the source subject and scene. Change only the rendering traits and edits requested in the brief.
