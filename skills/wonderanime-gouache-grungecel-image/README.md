# WonderAnime Gouache/Grungecel Image

This public package consolidates the WonderAnime V3 and earlier Grungecel guidance into one skill. WonderAnime V3 remains the visual baseline. The older sunlit gouache and polished oil-like looks remain historical variants.

The historical analysis described reference images and near-misses. This package includes text guidance only. Use images supplied or cleared by their owner as style anchors. No visual calibration is claimed for this publication.

This package's Batcave contributions are available under [MIT](LICENSE). The visual reference and near-miss image sets remain private and have no public license grant.
