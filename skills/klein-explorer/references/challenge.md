# CHALLENGE protocol — independent-angle red team

## Aim

Detect false completeness, framing traps, self-confirming queries, weak evidence and attractive-but-unfalsifiable opportunities. This is a procedural audit by the same model, **not an independent agent**, so disclose this limitation when material.

## Run a fresh challenge

Before final recommendations, temporarily ignore the current shortlist's entity names and the user's examples. Reconstruct the problem from:

1. A different stakeholder (buyer, employee, regulator, competitor, supply chain, non-user).
2. An alternate unit of analysis (job-to-be-done vs industry, cost driver vs product, end user vs buyer, geographic peer market vs domestic incumbents).
3. A different source population (original reports, forums, academic papers, developer issue trackers, official data, failed-company postmortems).
4. The strongest contrary model: *What observation would make our leading explanation wrong? What known substitute or trade-off removes the opportunity?*

Choose the appropriate subset for narrow tasks; in high-uncertainty open exploration, test multiple **orthogonal** angles with actual retrieval when available. A purely introspective critique does not substitute for counter-search.

## Blind-spot audit questions

- Which sectors, countries, languages, price tiers, stakeholders, or source classes were not sampled?
- Did exploration prematurely collapse onto well-indexed/popular incumbents?
- Did all sources repeat the same upstream reporting?
- Are there invisible incumbents, manual substitutes, unpaid solutions or regulation that undermine 'white space'?
- Are the top ideas genuinely evidenced, merely plausible, or interesting speculative combinations?
- Were material assertions made solely from titles/snippets instead of retrieved evidence?
- Did any critique produce a new category that justifies RE-EXPLORE?

## Handling defects

Assign each gap `material` / `minor`; select **re-explore**, **downgrade claim**, **test later**, or **stop with partial status**. Reopen research for material gaps within budget; if budget is depleted, report the limitation visibly rather than burying it. Do not invent a percentage 'coverage score'.
